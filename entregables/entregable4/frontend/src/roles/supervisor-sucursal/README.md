# Rol: Supervisor de Sucursal

Zona de trabajo para los usuarios responsables de una sucursal específica.

Cada usuario con este rol debe tener una sucursal asignada. El backend filtra inventario, solicitudes, recepciones, alertas y movimientos usando la ubicación del usuario autenticado, para evitar que una sede vea o modifique información de otra.

Pantallas del rol:

- Dashboard
- Inventario
- Solicitudes de reposición
- Recepciones
- Alertas de stock
- Movimientos

No incluye reportes globales, compras, proveedores, categorías ni administración de sucursales.
